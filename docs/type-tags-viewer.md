# Type-colored edges and node tags

Implemented Logfire-style node-only `_tags`, inferred type-colored edges (including `str`, binary, and 2–3-type tuple gradients), a footer legend, tag filters with Any/All hide behavior, and collapsible left/right panes with persisted right-pane resizing.

## Why
This replaces ambiguous payload-kind styling with the data type actually flowing through an inferred edge while keeping node labels filterable without cluttering the graph.
