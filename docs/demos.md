# Demos

Published, self-contained interactive graph replays — no server required.

## [Document ingestion](https://themladypan.github.io/pylier/demos/ingest.html)

Branched text and image extraction with concurrent embedding. A document splits
into text and image paths, each path embeds independently, and the branches
converge at an indexing stage. The fastest way to see pylier's value: open it and
watch the branching, concurrency, and convergence in the graph.

## [Fulfillment workflow](https://themladypan.github.io/pylier/demos/fulfillment.html)

Nested assessment, inventory, shipping, and finalization branches. A deeper
branched pipeline showing how pylier renders a real-world multi-stage workflow
with nested calls and data handoffs across branches.
